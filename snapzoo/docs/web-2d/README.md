# 동물 왕국 (snapzoo)

총이나 칼 대신 **카메라 하나로** 동물 친구들을 만나는 사진 게임입니다.
초등학생 아이가 기획하고, 함께 바이브코딩으로 만들었어요.

- 주소: https://jsun.site/snapzoo/
- 파일: `index.html` 한 파일 (설치 필요 없음, 휴대폰·PC 브라우저에서 바로 실행)

## 어떻게 놀아요?

| 하는 일 | PC | 휴대폰 |
|---|---|---|
| 걷기 | 방향키 또는 WASD | 가고 싶은 곳을 눌러요 |
| 사진 모드 | 스페이스 또는 '사진 찍기' | '사진 찍기' 버튼 |
| 조준 | 방향키 | 화면을 손가락으로 끌어요 |
| 줌 | + / − 또는 마우스 휠 | + / − 버튼 |
| 찰칵 | 스페이스 | '찰칵' 버튼 |
| 그만 | Esc | '그만' 버튼 |

## 게임 구조

```
게임 접속 ─→ 코인 자동 적립 (1초에 1코인)
   │
광장 (도감관 · 사진 상점 · 다른 공간으로 가는 문)
   │
숲 · 초원 · 바다 · 설원 탐험
   │
동물 발견 → 사진 찍기 → 점수 판정
   │
처음 찍은 동물? ── 예 → 도감 새로 등록
   │              └ 아니오 → 점수가 더 높으면 최고 사진 갱신
   │
보상(별 1~3개 · 코인) → 상점에서 성장 → 다시 탐험
```

## 사진 점수 (100점 만점)

| 기준 | 점수 | 잘 찍는 법 |
|---|---|---|
| 가운데 | 40 | 동물을 네모 한가운데에 |
| 알맞은 크기 | 30 | 줌으로 너무 작지도, 너무 크지도 않게 |
| 특별한 순간 | 30 | 동물이 반짝이며 움직일 때 찰칵! |

- 80점 이상 ★★★ · 55점 이상 ★★ · 그 밖 ★
- 처음 찍은 동물: 20 + 별×10 코인 (귀한 동물은 +30)
- 더 잘 찍어 최고 사진 갱신: 별×5 + 오른 점수의 절반

## 구역과 동물 (16종)

| 구역 | 여는 방법 | 동물 |
|---|---|---|
| 숲 | 처음부터 | 다람쥐, 부엉이, 여우, 곰(귀함) |
| 초원 | 처음부터 | 토끼, 나비, 양, 사슴(귀함) |
| 바다 | 상점 100코인 | 게, 거북, 돌고래(귀함), 문어 |
| 설원 | 상점 300코인 | 펭귄, 물범, 북극늑대, 북극곰(귀함) |

겁 많은 동물(다람쥐, 여우, 토끼, 사슴, 북극늑대)은 가까이 가면 도망가요. 멀리서 줌으로 찍어요.

## 상점

| 물건 | 가격 | 효과 |
|---|---|---|
| 빠른 운동화 | 80 | 걷는 속도가 빨라져요 |
| 바다 길 열기 | 100 | 바다 구역이 열려요 |
| 망원 렌즈 | 150 | 최대 줌 2배 → 4배 |
| 설원 길 열기 | 300 | 설원 구역이 열려요 |

## 고쳐 보고 싶을 때

`index.html` 안의 `<script>` 맨 위에서 바꿀 수 있어요.

- `SPECIES` : 동물 이름, 그림(이모지), 크기, 빠르기, 겁 많음(`shy`), 귀함(`rare`), 특별한 순간(`act`)
- `SHOP` : 상점 물건과 가격
- `PORTALS` : 광장의 '다른 공간으로 가는 문'. `url` 칸에 주소를 넣으면 그 문으로 이동해요.

```js
{ id:'camp', name:'캠핑장', x:880, y:770, color:'#ff9f43', url:'https://예시주소/camp/' },
```

## 저장

코인, 도감, 산 물건은 **지금 쓰는 브라우저에만** 저장돼요 (localStorage).
다른 기기에서 이어 하려면 나중에 Firebase(파이어스토어) 연동을 붙이면 됩니다.
